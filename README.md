​# Git Practice Handbook - Version B
A practical guide for Git, Branching, and Pull Requests
## Useful Git Commands

1. `git checkout -b branch-name`: Create a new branch
2. `git commit -m "commit message"`: Save/commit changes
3. `git push origin branch-name`: Push changes to GitHub
## How to run script
Run `python app.py` to see the greeting message.
